<summary>What Git branches are available?</summary>

This project uses multiple branches:

- `master`, containing the latest stable version (default branch)
- `development`, containing the current development version
- `website`, containing the current website content; pushing to this branch
  automatically triggers publication of the main website

All development is conducted in the `development` branch, and
contributions via Pull Requests should be directed to this branch.

When new releases are published, the `master` branch is rebased
onto `development`.
