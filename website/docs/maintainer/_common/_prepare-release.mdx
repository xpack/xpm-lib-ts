### Prepare the release

- Terminate all running tasks (**Terminal** → **Terminate Task...**)
- Switch to the `development` branch (`git checkout development`)
- `npm run fix`
- If there are changes, **commit** them to the `development` branch
- `npm run test`
- Update the latest commits with `npm run update-changelog`
- Update `CHANGELOG.md`; add a line such as _**\* v5.0.0 published on npmjs.com**_
- **Commit** with the message _**CHANGELOG: publish npm v5.0.0**_
- Check the list of files included in the npm package:
  ```sh
  npm run npm-pack
  ```
- If the list is not correct, fix `.npmignore`; since this file is generated,
  change its template in the helper project and regenerate it with the
  **generate-top-commons** npm script
- Redo `npm install` to ensure `package-lock.json` is up-to-date
- Redo `npm run npm-link-helpers` to update to the linked helpers
